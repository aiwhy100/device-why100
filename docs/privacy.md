# 儿童隐私与内容

AI为什么100 是给孩子用的。接入的设备和应用请一起遵守下面几条（也是我们自己的做法）。

## 录音

- **只用来识别成文字，识别完立即丢弃**。不保存录音，不写日志，不上传到识别以外的地方。本仓库的固件、网关、示例都是这样做的；[asr-server](https://github.com/aiwhy100/asr-server) 也只在内存里识别。
- 设备上录音缓冲用完就清零（见固件 `handle_question()`）。
- 不要在设备上做常开监听；用「按住说话」或唤醒词，让孩子和家长清楚什么时候在录音。

## 个人信息

- 只上传**问题文字**。设备 ID 用匿名的（MAC、随机 UUID），**不要传孩子的姓名、年龄、手机号、位置**。
- 合作厂商的 `externalUserId` 同理。

## 告知与同意

面向儿童的产品上线前：

- 隐私政策里写明：录音会上传到（你们的 / AI为什么100 的）服务器识别成文字，识别后立即丢弃、不保存，问题文字用于制作视频。
- 首次使用时取得**家长**同意。
- 遵守你所在地区的法规（中国大陆：《个人信息保护法》《儿童个人信息网络保护规定》等）。

## 内容

- AI为什么100 在提交时和制作前两道把关：不适合孩子的问题（暴力、恐怖、成人话题等）直接拒绝，返回 422，**不扣额度**。设备收到 422 时温和地请孩子换一个问题，不要复述敏感词。
- 视频按 5–12 岁的标准自检画面和用词，结尾有一个安全的「你可以试试」小实验。
- 视频由 AI 生成。在设备、App、网页上播放时，请标注「AI 生成」。

## Key 的安全

- 个人开发者：一台设备一个 Key，丢了就在 <https://aiwhy100.com/app/>「设置 → API Key」删掉。
- 量产设备：不要把 Key 写进固件，用[网关](gateway.md)（Key 只在服务端），或者开启 ESP32 的 Flash 加密和 NVS 加密。
