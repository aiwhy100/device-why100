AI为什么100 · 网页刷机

给微雪 ESP32-S3-AUDIO-Board 刷上「AI为什么100」固件，不用装任何软件。

  1. 用电脑上的 Chrome 或 Edge 打开这一页（手机和 Safari 不行）。
  2. 用 USB-C 数据线把板子连到电脑。
  3. 点下面的按钮，选择出现的串口，等进度条走完（约 1 分钟）。

这个浏览器不支持网页刷机，请换成电脑上的 Chrome 或 Edge。 需要用 https 打开这一页。

找不到串口：按住板子上的 BOOT 键，再按一下 RESET，松开 BOOT 后重试。

刷完之后
  1. 板子会说「请爸爸妈妈打开手机的无线网设置……」，灯环青色呼吸。
  2. 手机连上 AI为什么100-xxxx 热点，会自动弹出设置页（没弹出就打开 192.168.4.1）。
  3. 填 WiFi（2.4G）和 API Key（在 aiwhy100.com/app「设置 → API Key」创建），保存。
  4. 板子说「我准备好啦」，按住任意按键问一个「为什么」吧！
